Detailed Description

Experimental: interface for a device adapter implemented by the client of MMCore.

This is an alternative to loading a device adapter from a library: derive from this class and pass an instance to CMMCore::loadClientDeviceAdapter().

This interface is experimental and subject to change. It is a C++ API and is not intended to be exposed as-is in language bindings; binding layers may use it to implement their own device adapter mechanisms.

The devices created must be compiled against the same MMDevice (device interface version) as MMCore. This is not checked.

None of the member functions may throw exceptions.
